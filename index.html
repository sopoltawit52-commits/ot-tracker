เชื่อมต่อ Google Sheets Web App

วาง Web App URL ที่ได้จากการ Deploy Google Apps Script เพื่อใช้ Google Sheets เป็นฐานข้อมูลจริง

วิธีนำขึ้น GitHub Pages (ฟรี)

  1. กดปุ่ม ดาวน์โหลด index.html ด้านล่าง เพื่อบันทึกไฟล์เว็บแอปนี้ลงเครื่อง
  2. สร้าง Repository ใหม่บน GitHub (เช่น ot-tracker) แล้วอัปโหลดไฟล์ index.html
  3. ไปที่ Settings > Pages เลือก Branch main และโฟลเดอร์ / (root) แล้วกด Save
  4. เปิดลิงก์ GitHub Pages ของคุณ แล้วนำ Web App URL จาก Google Sheets มาใส่ในช่องด้านบน

โค้ดฐานข้อมูล Google Sheets (Apps Script)

เปิด Google Sheets > ส่วนขยาย (Extensions) > Apps Script > วางโค้ดนี้ลงใน Code.gs



          

            
ขั้นตอนการ Deploy ใน Apps Script:

            
กด Deploy > New deployment > Web app • ตั้งค่า Execute as: Me และ Who has access: Anyone จากนั้นคัดลอก Web App URL มาวางในช่องด้านซ้าย
